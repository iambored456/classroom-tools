# MPM2D Cycle 4 prerequisite review

## Workbook scope

The app uses all 88 skill IDs and names from the **Skill Index** in *MPM2D Cycle 4 Skill Tree.xlsx*. The **Skill Tree** overview supplies the five Cycle 4 branches, and **Question Routes** supplies 26 examples of how those skills appear in course work. The app records the original **Needs first** entry and a rationale on each skill. Shared skills have one ID and one evidence history per attempt.

The first bank covers F01–F11 and 26 shared number and algebra skills. The full map includes the formula, applications, circles and systems branches, plus foundation skills outside the initial bank. Q09 remains visible as the connection between factoring roots and graph intercepts.

## How to read the reviewed map

- An **essential** link applies to every item for the skill. Each row of the essential list is required. Within a row, any listed route can satisfy that requirement. For example, applications can use a demonstrated factoring or formula route to solve an equation, alongside their modeling and interpretation requirements.
- A **supporting** link describes preparation, verification or a skill that applies to only some prompts. It guides sequencing and practice, while the actual item can specify a narrower requirement.
- An **item-level requirement** applies only to that item. An equation already set equal to zero can bypass A14. An equation with a product to expand can require A07. A chosen factoring item specifically requires the method or methods used by the expression.
- The map includes all 246 source prerequisite links. The review changed how links can affect availability and added the links below. The original list, reviewed links and reasoning are kept together in the skill data.

| N04–N12, N16; A04–A05 | Use recall, grouping, factor-pair search and coefficient arithmetic as supporting preparation where the prompt allows a direct check. | A student can reason from equal groups, compute a basic quotient, compare signed numbers or show an exponent rule even when recall is slow. | A07–A10, A12, A14, A18 | Match gates to the steps actually used. A08 can assess the sign reversal directly. A09 and A10 require the operations that make up the combined skill. Multiplying powers, factoring out denominators, removing brackets and collecting terms vary with the starting equation. |
| F01–F05 | Require numerical GCF and power division for greatest-common-monomial items. Signed sums and products feed F02, which feeds monic trinomials and the AC method. Treating expansion as support leaves the relevant factoring method available when a student can construct the factors. |
| F06–F07 | Add N16, recognizing perfect squares, as essential. Treat N17, A06 and A09 as supporting. | The initial pattern checks use exact square terms. Estimating irrational roots or expanding two general binomials is unnecessary for recognizing these squares. |
